### 4. Version Control

GitHub digunakan sebagai tempat penyimpanan source code dan dokumentasi proyek.

Version control digunakan untuk:

- Menyimpan perubahan proyek.
- Mencatat riwayat pekerjaan.
- Memudahkan kerja sama anggota tim.
- Menjaga dokumentasi proyek.
- Memudahkan proses pengembangan pada sprint berikutnya.

### 5. Alur Version Control

1. Membuat atau memperbarui file.
2. Memeriksa perubahan.
3. Melakukan git add.
4. Melakukan git commit.
5. Melakukan git push ke GitHub.
6. Memastikan perubahan telah masuk ke repository.

### 6. Contoh Commit Sprint 1

git add .

git commit -m "Complete Sprint 1 documentation"

git push origin main
