# UX DESIGN
## Digital Twin Product Kopi Gayo

### 1. Tujuan UX

UX Design bertujuan memastikan pengguna dapat menemukan dan memahami informasi Digital Twin Product Kopi Gayo dengan mudah melalui tampilan dan navigasi website yang sederhana.

### 2. Target Pengguna

| Pengguna | Kebutuhan |
|---|---|
| Pengunjung/Konsumen | Melihat informasi produk Kopi Gayo dengan mudah. |
| Pelaku Usaha | Menyajikan identitas dan informasi produk secara digital. |
| Tim Pengembang | Memiliki rancangan pengalaman pengguna yang jelas. |

### 3. User Persona

**Nama:** Andi  
**Usia:** 22 tahun  
**Peran:** Pengunjung/Konsumen

**Tujuan:** Mengetahui asal dan karakteristik produk kopi sebelum membeli.

**Kebutuhan:** Informasi produk yang ringkas, jelas, mudah diakses melalui smartphone, dan dapat diakses melalui QR Code.

**Pain Point:** Informasi produk sering tersebar sehingga pengguna sulit mendapatkan informasi lengkap dalam satu tempat.

### 4. User Flow

1. Pengguna membuka website.
2. Pengguna melihat halaman Beranda.
3. Pengguna memilih menu Produk.
4. Sistem menampilkan produk Kopi Gayo.
5. Pengguna memilih produk.
6. Sistem menampilkan detail Digital Twin produk.
7. Pengguna dapat melihat QR Code untuk mengakses informasi produk.

### 5. Sitemap

Website

├── Beranda  
├── Tentang  
├── Produk  
│   └── Detail Produk / Digital Twin  
└── QR Code

### 6. Rancangan Halaman

| Halaman | Komponen | Tujuan |
|---|---|---|
| Beranda | Navbar, judul, deskripsi, menu produk | Memperkenalkan sistem |
| Tentang | Informasi Digital Twin | Menjelaskan proyek |
| Produk | Daftar/kartu produk | Memilih produk |
| Detail Produk | Informasi produk | Menampilkan informasi lengkap |
| QR Code | QR Code dan informasi akses | Memudahkan akses Digital Twin |

### 7. Prinsip UX

- Navigasi sederhana dan konsisten.
- Informasi produk disusun secara terstruktur.
- Tampilan dapat digunakan pada perangkat mobile dan desktop.
- Informasi penting mudah ditemukan.
- QR Code mudah diakses oleh pengguna.
