# AGILE METHODOLOGY
## Digital Twin Product Kopi Gayo

### 1. Tujuan

Agile Methodology digunakan untuk mengatur pengembangan Digital Twin Product Kopi Gayo secara bertahap melalui sprint. Sprint 1 berfokus pada perencanaan produk, kebutuhan pengguna, rancangan UX, perhitungan Function Point, dan setup awal proyek.

### 2. Product Vision

Membangun website Digital Twin Product Kopi Gayo yang menyajikan identitas dan informasi produk kopi secara digital sehingga pengguna dapat mengetahui informasi produk dengan mudah melalui website dan QR Code.

### 3. Product Backlog

| ID | Backlog | User Story | Prioritas |
|---|---|---|---|
| PB-01 | Halaman Beranda | Sebagai pengguna, saya ingin melihat halaman utama agar memahami tujuan sistem. | High |
| PB-02 | Halaman Tentang | Sebagai pengguna, saya ingin mengetahui informasi tentang Digital Twin Kopi Gayo. | Medium |
| PB-03 | Daftar Produk | Sebagai pengguna, saya ingin melihat produk Kopi Gayo yang tersedia. | High |
| PB-04 | Detail Produk | Sebagai pengguna, saya ingin melihat informasi detail produk. | High |
| PB-05 | QR Code | Sebagai pengguna, saya ingin menggunakan QR Code untuk mengakses informasi Digital Twin. | High |
| PB-06 | Dokumentasi Proyek | Sebagai tim, kami ingin memiliki dokumentasi proyek yang terstruktur. | High |

### 4. Sprint Goal

Menghasilkan Product Release 1 berupa rancangan dan setup awal website Digital Twin Product Kopi Gayo, lengkap dengan dokumentasi Agile, UX Design, Function Point, dan repository GitHub.

### 6. Definition of Done

- Dokumentasi Sprint 1 tersedia di repository GitHub.
- Fungsi utama website telah diidentifikasi.
- Rancangan UX tersedia.
- Perhitungan Function Point telah dibuat.
- Project setup telah didokumentasikan.
- Perubahan telah dilakukan commit dan push ke GitHub.
